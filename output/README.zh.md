# `output/` · 筛选产物,不是账本

本目录里的一切都是**研究输出**:每日筛选跑完后写出的中间结果,用于复核与复现漏斗。
**其中没有任何一份是持仓。**

账本本身在 [`data/ledger/`](../data/ledger/):

| 文件 | 是什么 |
|---|---|
| `data/ledger/constituents.csv` | **持仓。**一行一只成分,含入册日期、入册价、入册权重。每半年审查一次(1 月与 7 月,METHODOLOGY §7.1);入场后永不再平衡(§7.3)。 |
| `data/ledger/index_level.csv` | 每日指数点位。只追加,一个交易日一行。 |

## 本目录各文件

| 文件 | 是什么 |
|---|---|
| `funnel_YYYY-MM-DD.csv` | 当天各筛选层各有多少家通过。 |
| `candidates_YYYY-MM-DD.csv` | L4 幸存者去重后的完整排名。 |
| `book1_index_YYYY-MM-DD.csv` | **每日排名快照,不是账本。**见下方说明。 |
| `index_chart.svg` | 由 `src/render_chart.py` 从 `index_level.csv` 生成,中英两份 README 均嵌入此图。 |

## 关于 `book1_index_*.csv`

这个名字读起来像「第一本账的成分」。它不是。它是**假如今天开账**筛选程序会选出的名单,
每个交易日从头重算一次。持仓不跟着它走。

两者从一开始就是分开的,而且是有意如此。2026-07-20 至 2026-07-27 之间,快照进出了四只
(VRSK 进了又出、MCO 进了又出、BR 出去又回来、GRMN 回来),而账本一动没动。这种换手是噪音
不是信号:候选池很小,排名末段几只的得分彼此相差只有约 0.004,一天的价格波动就能把它们
重排。§7.3「入场后永不再平衡」这条规则存在的意义,正是把这种噪音挡在账本之外。

**要知道持有什么,读 `data/ledger/constituents.csv`。**本目录回答不了这个问题。

文件名维持原样:这些文件逐日公开发布并有外部存档,给历史产物改名会让已被记录在别处的
路径失效。改名只能向前生效,且应当单独提交。
